### Case Study Source Notes: SO Tool Onboarding / Intro Flow

*Raw notes for future case study write-up.*

**What it is:** A multi-step quiz-style onboarding flow that precedes the "Super Objective (SO) Tool" self-discovery exercise (intro screen: *"You're about to discover your Super Objective™"*). Structured as a problem-agitation-solution sequence:
1. Pain-point selection ("Which of these is most challenging for you right now?")
2. Multi-select resonance screen ("Select 3 options that resonate most with you")
3. "Here's what that is costing you": consequence list tied to the selected pain point
4. Reframe screen: pain point flips to a positive outcome ("I'm stuck and don't know why" → "You see the path forward"), with supporting benefit list
5. Transition into the full SO Tool

**Purpose:** Gives users an early, personalized glimpse of the result before they hit the signup form, building buy-in ahead of conversion. Includes logic that personalizes the end result based on the user's answers.

**My role:** Designed the UI and the flow logic in WeWeb, working from a design spec provided by the client. Did not originate the underlying content/copy strategy; implemented and designed the experience from spec.

**Metrics:** None available for this specific flow (separate from the 63% completion rate, which is for the SO Tool overall).
